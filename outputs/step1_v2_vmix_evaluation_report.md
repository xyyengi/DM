# Step 1：V2 与 v-mix 重新实验及高级评价总结

## 1. 重新实验目的

由于之前服务器实例已释放，旧 checkpoint 和生成样本文件无法追溯，当前本地只保留了历史 `metrics.txt` 和汇总表，无法重新计算极端场景、尾部风险和 rank histogram 等高级指标。因此本轮重新训练并生成了两个关键版本：

| 版本 | 实验名 | 生成目标 | 条件引入方式 | 代表意义 |
|---|---|---|---|---|
| V2 | `v2_csdi_cond_actual_given_forecast_168h` | actual | 将 forecast 拼接进网络输入，不使用 guidance | forecast 条件扩散基线，主要检验“直接生成 actual 时，forecast 条件是否能保持覆盖率和时序结构” |
| v-mix | `v_mix_residual_forecast_concat_guidance` | residual = forecast - actual | 网络输入 `[x_t, forecast, time_encoding]`，并在采样阶段使用 forecast-error interval guidance | 当前主线模型，检验“残差建模 + forecast 条件 + 时间编码 + guidance”是否能提升精度 |

本轮选择 V2 和 v-mix，是因为二者分别代表当前最重要的两条路线：V2 更像稳健条件生成基线，v-mix 更像高精度残差修正主线。重新跑这两个版本，可以判断 v-mix 是否真的值得继续作为主线推进。

## 2. 新增评价指标

除原有 MAE、CRPS、Coverage、Width、ACF MAE 外，本轮补充了更面向风险场景的评价。

| 指标类别 | 指标 | 中文说明 |
|---|---|---|
| 全测试集指标 | MAE / RMSE | 生成场景均值与真实值之间的平均绝对误差和均方根误差，衡量中心精度 |
| 概率分布指标 | CRPS | 连续秩概率评分，衡量生成分布与真实观测的一致性，越低越好 |
| 可靠性指标 | Coverage 100% / 90% / 80% | 真实值落入生成场景区间的比例，衡量不确定性覆盖是否充分 |
| 区间紧凑性 | Interval Width | 生成场景区间宽度，越小表示区间越紧，但过小可能导致欠覆盖 |
| 时序结构 | ACF MAE | 自相关函数误差，衡量生成场景是否保留时间相关结构 |
| 爬坡特性 | Ramp Error / Extreme Ramp Error | 衡量生成场景对快速变化和极端爬坡的刻画能力 |
| 尾部风险 | P95/P99 MAE、Tail Coverage | 评价高误差尾部和极端值区域的覆盖能力 |
| 校准诊断 | Rank Histogram | 判断真实值在生成样本分布中的秩位置，若两端过多，说明分布偏窄或偏移 |

极端场景阈值只使用训练集分位数拟合，避免测试集信息泄露。定义的极端窗口包括：低新能源、高负荷、高净负荷、高爬坡和复合极端场景。

## 3. 全测试集结果

| 模型 | MAE ↓ | RMSE ↓ | CRPS ↓ | Coverage 100% ↑ | Coverage 90% ↑ | Width 100% ↓ | ACF MAE ↓ | Ramp Error ↓ |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| V2 | 0.1065 | 0.1506 | **0.0787** | **90.56%** | **83.92%** | 44.72 | **0.0555** | 0.0220 |
| v-mix | **0.1006** | **0.1427** | 0.0824 | 63.92% | 55.96% | **16.75** | 0.1026 | **0.0185** |

从全测试集看，v-mix 的平均误差和 RMSE 更低，区间也明显更窄；但 V2 的 CRPS、Coverage 和 ACF MAE 更好，说明 V2 在概率可靠性和时序相关结构上更稳。

## 7. 主要结论

1. v-mix 在平均误差上仍有优势，说明 residual 建模和 forecast 条件确实能提升中心轨迹精度。
2. v-mix 的区间显著更窄，但 coverage 明显不足，尤其 wind coverage 和 wind tail coverage 问题严重。
3. V2 虽然 MAE 略高，但 CRPS、coverage 和 ACF MAE 更稳，说明它更好地保留了概率分布宽度和时序相关结构。
4. 极端子集上，v-mix 仍然表现出“低 MAE、低 coverage”的特征，说明问题不是只出现在普通场景，而是贯穿整体和风险场景。
5. 当前 v-mix 不能写成“全面优于 V2”。更客观的表述应为：v-mix 提高了平均精度，但存在明显欠覆盖和风电尾部风险刻画不足。

## 8. 下一步建议

建议先不直接引入完整 PGDM，也暂时不做大规模 guidance sweep。下一步做一个最小 guidance 诊断实验即可。

建议设置：

| 实验 | guidance scale | 目的 |
|---|---:|---|
| no-guidance | 0.0 | 判断不使用 guidance 时，v-mix coverage 是否恢复 |
| weak-guidance | 0.3 | 判断弱引导是否比当前 0.5 更平衡 |
| current | 0.5 | 当前正式 v-mix 结果，作为对照 |

如果 `guidance=0` 后 coverage 明显恢复，说明当前主要问题是 forecast-error interval guidance 拉得过强；如果 `guidance=0` 后 coverage 仍然很低，则说明 residual diffusion 本身生成分布偏窄，需要进一步引入 pattern features 或改进训练策略。

PGDM pattern-lite 应放在 guidance 诊断之后。它不应直接复刻完整 PGDM 的 contrastive encoder、VAE 和 latent diffusion，而是先轻量引入 forecast-derived pattern features，例如平均功率、最大/最小功率、波动幅度、爬坡幅度和净负荷模式，用来增强模型对低新能源、高净负荷和高爬坡场景的条件表达能力。
