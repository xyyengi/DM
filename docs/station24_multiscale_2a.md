# Station24 Experiment 2A：多尺度固定图混合

## 实验目的

当前 State V1 只在 U-Net 瓶颈层进行一次跨场站图传播。此时 168 h 已经下采样为 42 h，局部突升、突降和短时爬坡的边界可能在进入空间交互前被平滑。实验 2A 将同一张固定地理图分别用于 168 h、84 h 和 42 h 三个尺度，让跨站同步变化在细、中、粗时间分辨率上都能被建模。

本实验只改变图混合位置，不叠加新的状态指标：

- 仍为24个风光场站，输入和输出场站数不变；
- 仍使用 State V1 的4个状态量：低出力、高出力、向上爬坡、向下爬坡；
- 仍生成 `actual - forecast` 残差，再加回发布预测；
- forecast condition、recent error、State Encoder、FiLM、固定地理邻接矩阵均保持不变；
- 损失函数、训练轮数、早停、80成员验证、500步反向采样和物理投影均保持不变。

## 数据流

```text
24站发布预测 + 可用条件
        ↓
共享场站时间编码 + State V1 Encoder
        ↓
ResUNet encoder_0（168 h）→ Fixed Graph Mix + 独立门控
        ↓
ResUNet encoder_1（84 h） → Fixed Graph Mix + 独立门控
        ↓
ResUNet bottleneck（42 h）→ Fixed Graph Mix + 独立门控
        ↓
ResUNet decoder + FiLM
        ↓
24站×168 h残差场景 → 加回forecast → 物理投影
```

每个图块采用残差式传播，示意为：

\[
H' = H + \sigma(g_s)\,W_s(A_{geo}H),
\]

其中 \(s\in\{168,84,42\}\) 表示尺度，\(A_{geo}\) 是与基线相同的固定地理邻接矩阵，\(g_s\) 是各尺度独立学习的门控。门控结果会写入训练和生成元数据，用于判断模型实际使用了哪个尺度。

## 参数与过拟合约束

新增的只有168 h和84 h两个图块的归一化仿射参数、1×1投影和独立门控。当前通道宽度为32和64，参数增量为：

\[
(32^2+3\times32+1)+(64^2+3\times64+1)=5,410.
\]

相对 State V1 约77万参数只增加约0.7%，没有增加条件维度，适合290个训练发布窗口下的第一轮结构实验。三个门控均以与原瓶颈图相同的保守初值启动。

## 与 CDSG 的关系

该设计借鉴 CDSG 中“时间特征和空间特征需要在不同分辨率充分交互”的思想，但它是面向当前小样本数据的轻量化适配，并不是完整复现 CDSG：当前仍使用固定地理图和残差图传播，没有引入自适应邻接矩阵、双路 Transformer-GCN 或 Cross-Attention。这样可以先隔离验证“图传播是否介入得太晚”这一问题。

## 配对验证

基线为已完成的 `state_v1_fixed_graph`，只训练新的 `state_v1_multiscale_graph`。两者必须使用同一验证集、80个成员、生成种子和物理投影。流水线会自动完成：

1. 配置一致性和参数增量审计；
2. 训练多尺度候选模型；
3. 在验证集生成80成员场景；
4. 计算80%/90%/95%覆盖率、宽度、CRPS、联合分数、空间相关性和极端爬坡指标；
5. 运行风电事件时刻诊断，区分幅值欠覆盖与事件时刻偏早/偏晚；
6. 生成曲线包络图、比较报告并打包。

