# Station24 Experiment 2B：CDSG-lite并行时空融合

## 为什么不是照搬CDSG

当前任务只有290个训练发布窗口，直接加入完整Transformer、动态图学习和Cross-Attention会显著增加参数与过拟合风险。实验2B只保留CDSG最关键的结构思想：时间特征与空间特征从同一输入并行提取，再进行融合。

保持不变的部分：24场站轴、ResUNet、残差扩散目标、发布预测条件、recent error、State V1四个状态、FiLM、500步扩散、训练配置、固定地理图以及42 h瓶颈图混合。

唯一新增部分是在168 h高分辨率层加入一个轻量并行空间支路和动态融合门，不添加任何新的状态指标或输入通道。

## 当前项目适配的数据流

设进入U-Net第一层的隐变量为 \(H\)，已有预测条件编码为 \(C\)。

时间主分支仍是当前FiLM ResBlock：

\[
H^{temp}=F_{ResUNet}(H\mid t_{diff},C,S_{v1}).
\]

空间支路使用同一时刻的固定地理图，不在时间轴上做平滑：

\[
H^{sp}=W_s\left(A_{geo}(H+C)\right).
\]

融合门由时间特征、空间特征和已有预测条件共同决定：

\[
g_{b,i,\tau}=\sigma\left(g_0+W_g[H^{temp},H^{sp},C]\right),
\]

\[
H^{out}=H^{temp}+g_{b,i,\tau}\odot H^{sp}.
\]

其中 \(g\) 的形状为 `[batch, 24, 1, 168]`，会随场站和未来小时变化。时间分支始终是主路径，空间信息只作为门控残差加入，因此邻站平滑不会覆盖原有的局部突升、突降边界。

## 为什么只放在168 h尺度

实验2A已经证明，在168/84/42 h三个尺度重复传播同一固定图会增加区间宽度、改善光伏，但不能解决风电事件时刻，并使空间相关RMSE变差。2B只在完整168 h分辨率引入动态并行融合：

- 直接针对1/3/6 h风电事件；
- 不重复施加同一张图；
- 保留原42 h瓶颈图作为长期协同基线；
- 相比State V1只增加1,218个参数，约0.16%。

## 能否保证改善风电

不能保证。该结构能避免固定强度图传播导致的时间边界平滑，并允许模型在天气过程同步传播时使用邻站信息，因此比2A更针对风电问题。但如果发布预测和历史误差中完全没有天气突变发生时刻的线索，任何结构都无法稳定预测准确时刻，只能提高不同事件时刻的场景离散度。

## 配对判定标准

2B必须同时满足以下条件才能替代State V1：

1. 风电3 h和6 h事件时刻命中率不再像2A一样退化；
2. 风电CRPS不劣于基线，覆盖率提高不能只依靠显著加宽区间；
3. 风电峰值覆盖不下降；
4. 空间相关RMSE不出现2A的明显退化；
5. 光伏CRPS和峰值覆盖不能出现明显损失；
6. 动态门不能退化成所有场站、所有时刻几乎相同的常数。

本实验仍只训练一个新候选模型，复用既有State V1验证结果作为基线。后台入口：

```bash
bash run_station24_cdsg_lite_2b_pipeline.sh
```

脚本会连续完成训练、80成员验证生成、完整指标比较、典型包络、风电事件时刻诊断和打包。
