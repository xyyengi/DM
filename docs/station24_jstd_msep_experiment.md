# 24 场站 JSTD-MSEP 实验说明

## 1. 实验目的

Raw body-tail 作为正式基线保持不变。本实验只回答一个更具体的问题：在不使用验证期未来真实值的前提下，能否让 tail 成员学习“一个发布窗口内有几个事件、事件从何时开始、持续多久、风光分别偏离多深、是否多场站同步”，从而同时改善短时急变和长时持续深跌。

该版本不是再增加一个独立专家，而是把已经通过 H1 非因果上界实验验证过的事件渲染机制，替换为可在实际生成时使用的因果多段事件先验（Multi-Segment Event Prior, MSEP）。

## 2. 与 Raw body-tail、H1 的关系

- Raw body-tail：保留为正式基线，参数和结果均不覆盖。
- H1：利用真实事件参数验证 tail 是否具备按给定事件进行修正的能力，只是机制上界，不能作为实际预测结果。
- JSTD-MSEP：复用 H1 已验证有效的 slow/fast tail 与时空渲染器，但事件参数由当前可得功率信息预测并随机采样，生成阶段不读取未来 actual/residual。

模型仍只有 body 与 tail 两条生成路径。slow 与 fast 是同一 tail 内的互补时间尺度，不是第三、第四个专家：

\[
\epsilon = \epsilon_{body}
+M_{slow}(i,t)\odot\Delta\epsilon_{slow}
+M_{fast}(i,t)\odot\Delta\epsilon_{fast}.
\]

其中 slow 负责持续低偏、深度、持续时间与慢恢复，fast 负责 1/3/6 h 急变、局部波动与快速恢复。两个分量都受同一组连续事件参数约束，且通过互补尺度投影避免对同一频段重复修正。

## 3. 多段事件先验

每个样本最多保留两个连续事件段，每段表示为：

\[
h_e=(a_e,\tau_e,d_e,\delta_e^{wind},\delta_e^{solar},s_e),
\]

其中：

- \(a_e\)：事件是否有效；
- \(\tau_e\)：168 h 内的连续起点；
- \(d_e\)：实际连续持续时间，不划成 6/12/24 h 类别；
- \(\delta_e^{wind},\delta_e^{solar}\)：风、光事件幅度；
- \(s_e\)：系统级/多场站同步程度。

训练标签只由 train actual 与已发布 forecast 的误差构造。验证期 actual 只用于离线损失、早停和评价，不进入生成条件。事件目录先在各源内部桥接极短缺口；联合目录只合并真正时间重叠的风光事件，避免把相邻且方向相反的事件错误合并。

先验网络预测：

- 0/1/2 个事件的概率；
- 每个事件的 168 h onset 分布；
- duration、wind depth、solar depth 的位置与不确定度；
- sync 概率。

## 4. 为什么不再依赖失效的二分类门控

既有实验中的发布级事件门控容易坍缩为几乎恒定概率，无法回答“哪一个成员在什么时候发生什么事件”。本版本关闭该门控。

正式生成时，每个发布窗口固定抽取约 10% 的 tail 成员（500 个成员约 50 个），保证主体成员占绝对多数，普通分布不会因发布级误判而整体改写。事件数头仍学习 0/1/2 的完整分布，用于概率校准和诊断；在被选中的 tail 成员内，从非零事件数条件分布采样 1 或 2 个事件，再采样其时刻、持续时间和幅度。

因此，固定比例只控制“给多少次尾部尝试机会”，MSEP 决定“这些尝试分别在何时、何处、以何种强度发生”。

## 5. 当前严格因果条件

MSEP 只复用当前模型已有并在发布时可得的条件：

- 当前 168 h 风光发布预测及其多尺度表征；
- 发布前已观测 recent-error；
- train-only 历史功率构造的固定空间图及邻域状态；
- lead hour 位置编码。

本版没有再次把 forecast-only Top-K 历史窗口做平均，也没有同时加入 forecast revision 等额外机制。原因是旧检索实验已经暴露出 Top-K 权重接近均匀、关键事件被平均稀释的问题；本轮先把 H1 证明有效的“连续事件参数”从可得条件中学出来，避免一次混入多个无法消融的机制。若 MSEP 对 onset 的信息仍不足，后续再单独加入稀疏历史事件候选作为明确消融。

## 6. 训练与生成

- 初始化：H1 的 raw `model_state_dict`；
- 冻结：原 Raw body 主干和已失败的发布级门控；
- 更新：既有 JSTD tail 渲染器与新 MSEP 参数；
- 训练：最多 220 epoch，验证早停 patience 40，学习率 \(5\times10^{-5}\)；
- 正式生成：val 23 个窗口、每窗口 500 成员、固定 seed 424242、raw checkpoint；
- test：在模型和规则锁定前禁止生成。

结构化先验损失由事件数、onset、duration、wind/solar depth 和 sync 组成，并与原有 JSTD diffusion、slow/fast 多尺度约束联合训练。训练期可使用事件重放权重缓解 0 事件样本占多数，但不会把未来真实标签作为生成条件。

## 7. 必须同时评价的结果

普通质量：wind CRPS、aggregate wind CRPS、90% coverage、interval width、Energy Score、空间相关 RMSE。

事件质量：

- onset：\(\pm3/\pm6/\pm12\) h；
- 区间覆盖：25%/50%/75%；
- depth 覆盖：50%/75%/100%；
- 连续 duration MAE、depth MAE；
- 1/3/6 h ramp；
- 多场站同步极端与风光联合相关结构；
- all/body/tail 三组成员分开统计。

同时保存每个生成成员实际抽到的事件假设，避免只凭最终曲线猜测模型机制。

## 8. 成功与停止标准

优先级依次为：

1. 相比 Raw body-tail，持续深跌与短时急跌命中提高，onset/duration/depth 至少一项有明确改善；
2. 普通 CRPS 与 Energy Score 不发生不可接受退化，覆盖改善不能只来自区间无差别变宽；
3. 因果 MSEP 与 H1 上界的差距缩小，且保存的事件先验不是恒定时刻、恒定持续时间或单一事件数；
4. 若事件参数再次坍缩，先停止堆叠结构，依据审计结果定位是条件信息不足、类别不平衡还是渲染器耦合问题。

本实验的正式配置为 `configs/station24_jstd_msep_168h.yaml`，完整流水线为 `run_station24_jstd_msep_pipeline.sh`，中断后生成与评价恢复脚本为 `run_station24_jstd_msep_finalize.sh`。
