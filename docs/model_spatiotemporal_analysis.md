# 模型时空相关性处理分析文档

## 一、当前模型：多变量协同条件扩散模型 (Multi-Channel CDM)

### 1. 时间相关性处理

| 方法 | 实现位置 | 说明 |
|------|----------|------|
| **时间特征嵌入** | `TimeFeatureEmbedding` | 三尺度嵌入：小时(0-23)、周几(0-6)、月份(0-11) |
| **位置编码** | `SinusoidalPositionEmbedding` | 标准Sinusoidal位置编码，捕获序列位置信息 |
| **空洞卷积** | `DilatedConvBlock` | 空洞率[1,2,4,8]，感受野覆盖168点(一周) |
| **残差块时间注入** | `ResidualBlock.time_proj` | 时间特征注入到每个卷积层 |

**时间特征捕获能力：**
- 日内周期性：小时嵌入捕获（光伏白天高、负荷峰谷）
- 周周期性：周几嵌入捕获（负荷周末低）
- 季节性：月份嵌入捕获（风电冬春高、光伏夏季高）
- 长程依赖：空洞卷积扩大感受野

### 2. 空间相关性处理

| 方法 | 实现位置 | 说明 |
|------|----------|------|
| **多通道输入** | `(B, 3, 168)` | 风、光、负荷三通道协同建模 |
| **Res-UNet架构** | `ResUNet` | Encoder-Decoder + Skip Connection保留空间信息 |
| **多通道条件引导** | `compute_conditional_gradient` | Frobenius范数梯度修正，约束生成方向 |
| **通道融合** | 卷积层自动学习 | 通过卷积核自动学习通道间相关性 |

**空间相关性捕获能力：**
- 风-光-负荷之间的耦合关系
- 多变量协同条件约束生成方向

### 3. 优缺点分析

#### 优点
1. **时间建模全面**：三尺度嵌入(小时/周/月)覆盖多周期特征
2. **长程依赖捕获**：空洞卷积感受野覆盖168点，无需RNN即可建模长序列
3. **多变量协同**：三通道联合建模，捕获风-光-负荷耦合关系
4. **条件可控**：KDE条件区间 + 梯度引导，生成结果可控
5. **并行生成**：扩散模型可并行采样，效率高于自回归模型

#### 缺点
1. **空间建模有限**：仅通过卷积隐式学习通道关系，无显式空间注意力
2. **计算开销大**：扩散模型需多步去噪(50步)，训练和推理慢
3. **条件区间依赖KDE**：核密度估计对数据分布敏感，极端值可能估计不准
4. **缺乏跨变量注意力**：未显式建模风-光-负荷之间的动态交互
5. **位置编码简单**：仅用Sinusoidal编码，未考虑时间戳的物理意义

## 四、改进建议

### 时间相关性改进
1. **时间戳物理编码**：加入日出日落时间、季节等物理特征
2. **傅里叶特征**：使用傅里叶变换捕获周期性
3. **层次化时间编码**：年-月-日-时分层编码

### 空间相关性改进
1. **跨通道注意力**：显式建模风-光-负荷交互
2. **图神经网络**：将变量视为图节点，学习动态关系
3. **空间位置编码**：为不同变量添加可学习位置编码

### 模型架构改进
1. **条件扩散改进**：使用classifier-free guidance替代梯度引导
2. **加速采样**：DDIM、DPM-Solver等加速推理
3. **多尺度生成**：先生成粗粒度再细化
