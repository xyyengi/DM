# 主体—尾部模型原始最佳权重推理复核

## 目的

该实验不重新训练模型，只复用已完成主体—尾部实验的同一个
`model_best.pt`，将正式生成所用参数从 `ema_model_state_dict` 改为
`model_state_dict`。验证集、23个发布样本、每样本500成员、生成种子
424242、500步反向扩散和物理投影均保持不变。

这不是新模型对比，而是同一检查点的推理权重消融，用于回答：固定
`ema_decay=0.999` 是否因尾部模块训练较短而压弱了已经学到的尾部能力。

## 为什么需要复核

固定 EMA 更新为

\[
\theta_{\mathrm{EMA}}^{(k)}=
0.999\theta_{\mathrm{EMA}}^{(k-1)}+
0.001\theta_{\mathrm{raw}}^{(k)}.
\]

当前每个 epoch 约有19次优化器更新，最佳检查点位于约第20个 epoch，
即约380次更新。此时初始化权重仍占

\[
0.999^{380}\approx 68.4\%.
\]

主体参数来自成熟基线并被冻结，不受影响；尾部适配器和风险门控从接近
零的状态开始，因此固定0.999可能导致用于生成的EMA版本明显落后于原始
最佳参数。

## 动态 EMA（仅供未来重新训练）

主体—尾部配置增加幂律 warm-up：

\[
\beta_k=
\min\left(0.999,
1-\left(1+\frac{k}{\gamma}\right)^{-p}\right),
\qquad \gamma=1,\quad p=0.75.
\]

在第380次更新时，动态衰减约为0.9884；训练继续进行后逐渐接近上限
0.999。冻结主体仍逐次精确复制，warm-up只影响可训练的尾部和门控参数。
该配置不会改变已经完成的检查点，因此本次先用原始权重完成无重训复核。

## 服务器运行

可以显式传入先前主体—尾部实验目录：

```bash
bash run_station24_body_tail_moe_raw_regeneration.sh \
  outputs_shandong/station24/body_tail_moe_20260824_191036
```

脚本立即转入后台，并连续完成：

1. 同一最佳检查点原始权重的500成员生成；
2. 历史—空间基线与原始权重结果比较；
3. 同一检查点 EMA 与原始权重结果比较；
4. 主体—尾部隔离审计、专家专门化分析；
5. 风电事件时刻、预测归因和持续深跌尾部评价；
6. 结果打包。

测试集保持锁定，也不会再次训练模型。
